# Artem Pogosian

Analytics, machine learning and process automation. MSc student in Artificial Intelligence at HSE University, Faculty of Computer Science. I work with industrial data: equipment telemetry, failure prediction and turning routine analytics into tools.

### Projects

**[industrial-telemetry-anomaly](https://github.com/iamartempn/industrial-telemetry-anomaly)**
Anomaly detection in turbofan telemetry: five methods compared on NASA C-MAPSS. Isolation Forest warns about all 100 engines 12 cycles before failure with one false alarm per thousand healthy readings.
<br>Python, DuckDB, scikit-learn, Streamlit

**[Slovo](https://iamartempn.github.io/slovo/)**
A native macOS app that transcribes meetings and lectures and writes minutes entirely on-device, with no internet and no sign-up.
<br>Swift, SwiftUI, WhisperKit, llama.cpp

More this autumn: a remaining-useful-life prediction service, open-registry ETL pipelines and company financial risk scoring.
